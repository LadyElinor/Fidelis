# fidelis-contracts

Neutral cross-layer contracts for Fidelis.

This package may define serialization types, identifiers, provenance records, and BELARION result envelopes. It may also define neutral receipt structures for experimental research surfaces, such as mind-ontology probe receipts, so long as those structures remain observational and serialization-oriented. It must not contain substantive ethical lenses, warrant scoring, execution policy, or telemetry analysis.
